Mini RAG Lab — 벡터 유사도 웹 데모
================================

1. 실행해서 보는 방법 (권장)

Python 3가 설치되어 있으면 추가 패키지 설치 없이 실행할 수 있습니다.
프로젝트 루트(etnews-demo)에서 아래 두 줄을 순서대로 입력하세요.

  cd 01-mimic-rag
  python3 -m http.server 8000

이미 01-mimic-rag 폴더에 있다면 두 번째 명령만 실행하세요.

서버가 실행된 상태에서 Chrome, Safari, Edge 등의 브라우저를 열고
주소창에 아래 주소를 입력하세요.

  http://localhost:8000

시연하는 동안 터미널을 열어 두세요.
종료하려면 서버를 실행한 터미널에서 Ctrl+C를 누르세요.

8000번 포트가 이미 사용 중이라면 다음과 같이 다른 포트를 쓰세요.

  python3 -m http.server 8001

이 경우 브라우저 주소는 http://localhost:8001 입니다.

2. 서버 없이 여는 방법

Finder에서 이 폴더의 index.html을 브라우저로 열어도 동작합니다.
HTML, CSS, JavaScript 파일을 같은 폴더에 유지하세요.
인터넷 연결, API 키, npm 설치, Python 백엔드는 필요하지 않습니다.

3. 시연 순서

  (1) 처음 표시되는 '환불 배송 회원' 질문으로 세 문서의 점수를 비교합니다.
  (2) '환불 기한', '배송 기간', '회원 등급' 예시 버튼을 눌러
      유사도 막대와 문서 순위가 어떻게 바뀌는지 확인합니다.
  (3) 오른쪽 그래프에서 질문과 문서의 각도를 봅니다.
      각도가 작을수록 코사인 유사도가 높습니다.
  (4) 왼쪽 문서 카드를 누르거나 아래 '비교 문서'를 선택합니다.
      파란색으로 표시된 공통 bigram과 코사인 계산식을 확인합니다.
  (5) 질문을 직접 수정합니다. 입력 즉시 시각화가 갱신됩니다.
      '유사도 비교' 버튼을 누르면 최고 순위 문서가 상세 비교 대상으로
      선택됩니다. 직접 고른 문서는 다음 입력 중에도 선택이 유지됩니다.
  (6) 문서 문장 전체를 질문으로 넣으면 같은 벡터의 유사도 1을
      확인할 수 있습니다. '관련 없는 질문'은 검색 근거 없음의 예시입니다.

4. 계산 방식과 시각화의 의미

원본 (이 README.txt가 있는 폴더 기준): ../../etnews/2026-08-19/demo/mini_rag.py
이 폴더의 mini_rag.py는 원본을 그대로 복사한 참고 파일입니다.

원본의 세 문서와 다음 계산 방식을 JavaScript로 옮겼습니다.
  - 일반 공백(' ')을 제거합니다.
  - 연속된 문자 두 개(bigram)를 세어 빈도 벡터를 만듭니다.
  - 문서 벡터는 처음에 한 번 만들고 재사용합니다.
  - 질문과 각 문서의 코사인 유사도를 계산해 내림차순 정렬합니다.
  - 동점일 때도 원본처럼 문서 문자열의 내림차순을 적용합니다.

막대 길이는 0~1의 고정 척도이며, 정답 확률이 아닙니다.
각도 그래프는 질문과 각 문서 사이의 실제 각도를 한 평면에 모은
설명용 그림입니다. 문서 사이의 상대적인 각도나 거리는 나타내지 않습니다.
모든 문서의 유사도가 0이면 웹에서는 '검색 근거 없음'으로 안내합니다.
이는 0점이어도 첫 문서를 출력하는 원본 answer()와의 표시상 차이입니다.
빈 질문/한 글자 질문은 유사도 0으로 처리하며 각도는 표시하지 않습니다.
이 데모는 의미 기반 신경망 임베딩이나 LLM 답변 생성은 수행하지 않습니다.

5. 파일 구성

  index.html          화면 구조
  styles.css          반응형 화면 스타일
  app.js              입력 처리와 유사도 시각화
  rag.js              bigram 임베딩과 코사인 검색
  mini_rag.py         참고용 원본 Python 코드
  tests/rag.test.cjs   원본과의 결과 일치 및 경계값 검증
  README.txt          실행 및 시연 안내

6. 개발 검증 (선택)

Node.js 18 이상과 Python 3가 설치된 환경에서 이 폴더로 이동 후 실행:

  node --test tests/rag.test.cjs

웹 데모를 보는 데 Node.js는 필요하지 않습니다.
