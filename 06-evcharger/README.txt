06-evcharger — 강남역 주변 가용 전기차 충전소
============================================

아래 명령은 etnews-demo 저장소 루트 기준 상대 경로입니다.

1. 설치와 실행
--------------
Python 3.10 이상이 필요합니다. 최초 한 번:

  python3 -m venv 06-evcharger/.venv
  06-evcharger/.venv/bin/python -m pip install -r 06-evcharger/requirements.txt

실행:

  06-evcharger/.venv/bin/python 06-evcharger/server.py

브라우저 접속:

  http://localhost:8007/06-evcharger/

포트 충돌 시:

  06-evcharger/.venv/bin/python 06-evcharger/server.py --port 8017

접속 주소도 http://localhost:8017/06-evcharger/ 로 바꿉니다.
종료는 서버 터미널에서 Ctrl+C입니다.

RDFLib가 실제 SPARQL을 실행합니다. 별도의 지도 API 키, Jena/Fuseki,
LLM 또는 Node.js가 필요하지 않습니다. 의존성 설치 후 로컬 데이터만 사용합니다.
HTML 파일을 직접 열거나 python -m http.server로 실행하지 말고
반드시 위의 server.py를 사용하세요.

2. 시연 방법
------------
페이지를 열면 기본 조건(500m, 가용 1대 이상, 충전 중 비율 제한 없음,
이용 제한 없는 곳)으로 실제 SPARQL 검색을 실행합니다.

- 250m / 500m / 1km 버튼: 반경을 바꾸고 즉시 다시 검색합니다.
- 슬라이더: 100~1000m를 50m 단위로 조절합니다.
- 가용 충전기 최소 대수, 충전 중 비율 상한, 이용 제한 필터를 변경합니다.
- 슬라이더나 선택 항목을 바꾼 뒤 '주변 가용 충전소 찾기'를 누릅니다.
  변경 후 검색 전에는 이전 검색 결과임을 표시합니다.
- 초록 점: 조건을 만족하는 충전소. 번호는 가까운 순서입니다.
- 회색 점: 조건에서 제외된 충전소.
- 파란 중심점: 강남역 2호선 좌표.
- 점 또는 아래 목록을 선택하면 충전소 상세 정보가 바뀝니다.
- 회색 점도 선택할 수 있으며 제외 이유를 보여 줍니다.
- 충전기별 상태·출력·유형·기록 시각, 이용 시간과 주차 정보를 확인합니다.
- 하단에서 실제 SPARQL 및 선택 충전소 조회 데이터를 펼쳐 확인합니다.
- 조회 결과 전체를 JSON으로 내려받을 수 있습니다.

동심원은 250 / 500 / 750 / 1000m입니다. 반경 영역은 연한 초록색으로 표시합니다.
위쪽이 북쪽, 오른쪽이 동쪽입니다. 도로 지도가 아닌 좌표 기반 위치도입니다.
점 위치를 보기 좋게 옮기지 않으므로 인접 좌표의 점은 겹칠 수 있습니다.
겹친 후보는 아래 목록에서도 선택할 수 있습니다.
직선거리를 표현하며 도로 경로·도보/주행 시간은 계산하지 않습니다.

3. 확인할 수 있는 결과
---------------------
원본 데이터: 충전소 37곳, 충전기 117대.
기본 가용 1대 이상, 충전 중 비율 제한 없음, 이용 제한 없는 곳 기준:

  반경 250m: 반경 안 13곳 / 조건 충족 9곳 / 사용 가능 23대
  반경 500m: 반경 안 27곳 / 조건 충족 18곳 / 사용 가능 44대
  반경 1km: 반경 안 37곳 / 조건 충족 24곳 / 사용 가능 60대

반경 1km에서 이용 제한 포함, 충전 중 비율 50% 이하로 설정하면
원본 DSS 예제와 같은 31곳이 조회됩니다.
같은 조건에서 충전 중 비율을 제한하지 않으면 34곳입니다.
검색 결과는 실제 거리 오름차순이며 표시할 때만 미터 단위로 반올림합니다.
가장 가까운 후보는 서울시 강남구 글라스타워(약 109m)입니다.

4. 실제 처리 흐름
-----------------
브라우저 POST /api/search
 → 원본 RDF의 충전소·충전기를 SPARQL로 집계
 → 거리 / 가용 대수 / 충전 중 비율 / 이용 제한 FILTER
 → 가까운 거리순 결과
 → 동심원 마커, 목록, 상세 정보로 시각화

센터 좌표도 queries/center.rq의 SPARQL로 원본에서 조회합니다.
강남역 2호선: 경도 127.027912 / 위도 37.49799
충전소의 geo:asWKT POINT는 경도, 위도 순서로 읽습니다.

거리:
- 구면 지구 평균 반지름 6,371,008.8m의 haversine 공식을 사용합니다.
- 계산값을 작업 그래프에 ev:distanceMeters로 추가합니다.
- 실제 SPARQL FILTER(?distance <= 검색반경)가 후보를 제한합니다.
- 거리와 초기 방위각으로 동/북 오프셋을 계산합니다.
- 동심원 화면의 중심으로부터 거리와 필터의 거리가 일치합니다.
- 원본 RDF 파일에는 계산값을 쓰지 않습니다.

가용 상태:
- '사용가능'만 가용 대수에 포함합니다.
- '충전중' / 전체 충전기 수가 충전 중 비율입니다.
- '상태미확인', '통신이상', 누락은 가용 대수에서 제외합니다.
- '가용 최대 출력'은 사용 가능한 충전기만 대상으로 집계합니다.
- 현재 시각으로 상태를 예측하거나 변경하지 않습니다.

원본의 중복 및 상충 기록:
- 충전기 집계와 충전소 메타데이터 결합을 분리합니다.
- 중복 좌표/설명이 충전소 수와 가용 대수를 늘리지 않도록 처리합니다.
- 이용 제한 Y와 N이 동시에 기록된 3곳은 제한 있음으로 처리합니다.
- 상세 정보에 '기록 상충'을 표시하고 원본 설명도 함께 보여 줍니다.
- 이용 제한 정보가 없으면 기본 '이용 제한 없음' 필터에서 제외합니다.

5. 데이터 출처와 범위
--------------------
ontology101-book 저장소의 두 예제를 결합했습니다.
- ch08/gangnam.ttl: 장소, 지하철역, 충전소 좌표, 충전기 상태 원본
- ch07/dss/run_recommendation.py: SPARQL 집계 및 가용 대수/충전 중 비율 필터
원본 스냅샷과 참고 코드를 이 폴더 안에 복사했으므로 독립 실행됩니다.
원본 저장소는 수정하지 않았습니다.

화면은 저장된 관측 데이터로 동작하며 실시간 충전소 서비스가 아닙니다.
충전기마다 상태 기록 시각이 다르며 상세 표에 원본 시각을 표시합니다.
가용 상태가 현재도 유지되거나 방문·이용·예약이 가능함을 보장하지 않습니다.
원본에 강남역과 연결된 37곳만 대상으로 하며, 지역의 모든 충전소를
망라하는 지도나 전국 검색 기능은 아닙니다.

6. 파일 구성 (06-evcharger/ 안의 상대 경로)
------------------------------------------
server.py                      로컬 HTTP API
engine.py                      거리 계산, SPARQL, 조건 검증
index.html/styles.css/app.js    웹 UI, SVG 동심원, 결과/상세 연동
data/gangnam.ttl               원본 도시 데이터
queries/center.rq              강남역 중심 좌표 조회
queries/chargers.rq            충전기별 상태 조회
queries/stations.rq            가용 대수 집계 및 후보 검색
reference/run_recommendation.py 참고용 원본 DSS 코드 (실행하지 않음)
tests/test_evcharger.py        거리/집계/필터/API 검증

서버 재시작 시 실행 상태가 초기화됩니다. 같은 서버에서 새로고침하면
마지막 검색 조건과 결과를 복원합니다. 보존하려면 JSON을 다운로드하세요.
데이터 또는 질의 파일을 수정하면 서버를 재시작하세요.

7. 테스트
---------
저장소 루트에서:

  06-evcharger/.venv/bin/python -m unittest discover -s 06-evcharger/tests -v

10개 테스트에서 실제 SPARQL과 거리 함수를 실행합니다.
원본 37곳/117대 중복 집계 방지, 좌표/거리/방향 일치, 반경 변경,
원본 DSS 조건(31/34곳), 제한 상충 처리, 빈 결과, 오류 상태 제외,
가용 최대 출력, 질의와 화면 데이터 일치, API 요청 보호를 검사합니다.

문제 해결:
- 연결 실패: Python 서버와 접속 포트를 확인합니다.
- 조건 변경 후 결과 그대로: 검색 버튼을 누릅니다.
- 결과 없음: 반경을 넓히거나 최소 가용 대수/비율 조건을 조정합니다.
- 지도 점이 회색: 선택하면 거리/가용 대수/비율/제한 중 제외 이유가 나옵니다.
- 모듈 오류: .venv/bin/python과 requirements.txt 설치 여부를 확인합니다.
